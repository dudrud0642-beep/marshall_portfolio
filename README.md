# Marshall Portfolio

Marshall home audio website renewal concept built with semantic HTML, CSS, and vanilla JavaScript.

## Project structure

```text
.
├── index.html
└── assets
    ├── css
    │   └── styles.css
    ├── images
    │   └── *.webp
    └── js
        ├── editorial.js
        ├── feature-focus.js
        └── main.js
```

## JavaScript responsibilities

- `main.js`: navigation, product rail, filters, reveal effects, and scroll-driven sections
- `editorial.js`: editorial carousel and image parallax
- `feature-focus.js`: Stanmore IV feature chapter navigation

## Local preview

Serve the project root with any static file server and open `index.html`.

For example:

```bash
npx serve .
```
