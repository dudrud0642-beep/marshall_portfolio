2026.10.07 / FINAL REVIEW
01 / OVERVIEW

프로젝트 개요

제품 판매 중심의 정보 구조에 브랜드 헤리티지와 수면 경험을 결합해, 시몬스를 단순한 침대 브랜드가 아닌 ‘좋은 밤을 설계하는 라이프스타일 브랜드’로 보여주는 포트폴리오 리뉴얼입니다.

GOAL 01

제품 주목도 강화

신제품, 온라인 혜택, 시그니처 컬렉션을 큰 이미지와 짧은 메시지로 전달합니다.

GOAL 02

브랜드 경험 확장

테라스, 팩토리움, 헤리티지를 제품 탐색 흐름 안에 자연스럽게 연결합니다.

GOAL 03

몰입감 있는 탐색

스크롤 리빌, 슬라이더, 호버 반응을 사용하되 정보 이해를 방해하지 않도록 절제합니다.

02 / CONCEPT

디자인 콘셉트

핵심 키워드 Modern · Simple · Premium · Readable
컬러 블랙과 차콜을 기본으로 크림·웜그레이를 포인트로 사용해 침실의 안정감과 프리미엄 이미지를 표현합니다.
타이포그래피 한글 섹션 제목은 굵기 600으로 통일하고, 영문 슬로건은 세리프 계열로 브랜드 감성을 강조합니다.
레이아웃 제품과 공간 이미지를 넓게 사용하고, 설명 문장은 짧고 명확하게 배치해 빠르게 읽히도록 설계합니다.
모션 자동 슬라이드와 순차 등장 효과로 시선을 유도하며, 운영체제의 모션 저감 설정을 지원합니다.
03 / INFORMATION ARCHITECTURE

콘텐츠 흐름

01

관심 형성

메인 캠페인 배너와 신제품·온라인 혜택

02

신뢰 형성

좋은 밤을 만드는 기준과 시몬스의 수면 기술

03

제품 탐색

카테고리와 시그니처 컬렉션 비교

04

경험 연결

브랜드 아카이브, 매장 안내, 헤리티지 메시지

04 / DIFFERENCE

기존 공식 사이트와의 차이

배경과 분위기 공식 사이트의 밝고 판매 중심적인 화면과 달리, 블랙 기반의 전시형 레이아웃으로 프리미엄 브랜드 경험을 강화했습니다.
제품 노출 작은 상품 목록보다 풀 와이드 이미지와 대표 컬렉션을 먼저 보여줘 제품의 소재와 공간감을 강조했습니다.
콘텐츠 구조 공지·기사형 게시판 대신 브랜드 공간과 기술을 비주얼 아카이브로 재구성했습니다.
매장 안내 텍스트 목록 대신 이미지 카드 슬라이더로 구성해 공간의 성격을 먼저 이해할 수 있게 했습니다.
인터랙션 메인·제품·팝업·매장 슬라이더와 스크롤 모션을 추가해 탐색 리듬을 만들었습니다.
05 / RESPONSIVE & ACCESSIBILITY

반응형·접근성 전략

RESPONSIVE

네 단계 분기

1200·1100·900·600px을 기준으로 내비게이션, 카드 열 수, 팝업, 글자 크기를 조정합니다.

ACCESSIBILITY

키보드와 의미 구조

건너뛰기 링크, 명확한 제목 계층, 대체 텍스트, 포커스 표시, 키보드 슬라이드 조작을 제공합니다.

MOTION

선택 가능한 움직임

`prefers-reduced-motion` 환경에서는 애니메이션 시간을 최소화해 멀미와 피로를 줄입니다.
