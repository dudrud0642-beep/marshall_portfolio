### 이미지 교체 방법

1. **같은 파일명**으로 `assets/images/simmons/`에 덮어쓰면 HTML 수정 없이 반영됩니다.
2. 파일명을 바꾸면 `index.html`의 `src="assets/images/simmons/…"` 경로를 함께 수정합니다.
3. 사진은 JPG, 로고·아이콘은 PNG(투명)를 권장합니다. 파일당 **약 1MB 이하**로 압축합니다.
4. 교체 후 **1440 · 1024 · 768 · 390px** 너비에서 크롭과 텍스트 가독성을 확인합니다.

### Hero 1번 이미지 참고

## 2. 타이포그래피 (폰트 크기)

기본 서체: 본문 **Inter + Noto Sans KR**, 영문 슬로건·세리프 강조 **Cormorant Garamond** (`index.html` `<head>` Google Fonts).

반응형 기준: **900px**, **600px** (섹션 슬로건), 그 외 레이아웃 **1200 · 1100 · 900 · 600px**.

### 2-1. 섹션 큰 슬로건 (6개) — **크기 통일**

아래 문구는 CSS에서 **한 묶음**으로 같은 `font-size`를 씁니다.  
(`components.css` → `/* Final typography scale */`)

| 화면에 보이는 문구 | HTML 위치 | CSS 선택자 |
| --- | --- | --- |
| 새로운 밤을 만나보세요 | Promotions | `.promotions-head h2` |
| 좋은 밤을 만드는 세 가지 기준 | Intro | `.intro-head h2` |
| 나에게 맞는 휴식 찾기 | Find rest | `.section-heading h2` (#find-rest) |
| 더 깊은 잠을 위한 기술 | Collections | `.collection-head h2` |
| 잠과 문화, 그 사이의 모든 것 | Journal | `.section-heading h2` (#journal) |
| 가까운 곳에서 직접 경험하세요 | Stores | `.stores-head h2` |

| 화면 너비 | `font-size` (공통) |
| --- | --- |
| PC (900px 초과) | `clamp(38px, 4.8vw, 68px)` |
| 900px 이하 | `clamp(34px, 6.5vw, 48px)` |
| 600px 이하 | `clamp(31px, 8.8vw, 38px)` |

줄바꿈·글자 수 때문에 **보기에는** 차이가 날 수 있으나, **숫자상 동일**합니다.

**한곳에서 키우거나 줄이려면** `components.css`의 `.promotions-head h2, .intro-head h2, …` 블록만 수정하면 6개가 함께 바뀝니다.

---

### 2-2. 컨텐츠 박스 제목 — **크기 단계별 (통일 아님)**

카드·패널마다 선택자가 달라 **여러 단계**입니다. 통일하려면 아래 표를 기준으로 `components.css`에서 맞추면 됩니다.

| 화면에 보이는 제목 | CSS 선택자 | PC 기준 (대략) |
| --- | --- | --- |
| 더 깊어진 편안함, 새로운 컬렉션 | `.promotion-copy strong` | `clamp(29px, 3.2vw, 50px)` |
| 오직 온라인에서만, 특별한 혜택 | `.promotion-card-online .promotion-copy strong` | `clamp(26px, 2.5vw, 39px)` ※ 신제품 카드보다 작음 |
| 흔들리지 않는 편안함 / 250가지 수면 실험 / 50여 종 내장재의 조합 | `.intro-panel h3` | `clamp(27px, 2.5vw, 40px)` |
| Beautyrest / Frames | `.category-copy strong` | `clamp(36px, 4vw, 58px)` |
| Beautyrest Black 등 (컬렉션 슬라이드) | `.collection-info h3` | `clamp(36px, 4vw, 58px)` — 카테고리와 동일 규칙 |
| Simmons Terrace 등 (아카이브 카드) | `.journal-card h3` | `clamp(24px, 2.5vw, 36px)` |
| 시몬스 테라스 / 시몬스 갤러리 | `.store-card h3` | `clamp(24px, 2.5vw, 36px)` — 아카이브와 동일 규칙 |

600px 이하 예시 (고정값 혼합):

- 프로모 카드 제목: **28px** (`.promotion-copy strong`)
- 인트로 패널 제목: **24px** (`.intro-panel h3`)
- 카테고리 strong: **40px** (`.category-copy strong`)
- 매장 카드 h3: **24px** (`.store-card h3`)
